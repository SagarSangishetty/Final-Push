========================================================

Route 53 - Failover Routing
===========================================

What is Failover Routing?
-------------------------

Failover Routing provides automatic Disaster Recovery.

Traffic goes to the Primary endpoint.

If the Primary becomes unhealthy,

Route 53 automatically returns the Secondary endpoint.

--------------------------------------------------

Interview Answer

Failover Routing is used for disaster recovery. Route 53 continuously monitors the primary endpoint using health checks. If it becomes unhealthy, Route 53 automatically returns the secondary endpoint.
