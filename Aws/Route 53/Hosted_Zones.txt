===========================================
Hosted Zone
===========================================

What is a Hosted Zone?

A Hosted Zone is a container that stores all DNS records for a domain.

It tells Route 53 how to resolve domain names.

Example

Domain

ecommerce.com

↓

Hosted Zone

↓

1. Public Hosted Zone

Accessible from the Internet.

2. Private Hosted Zone

Accessible only inside a VPC.

Interview Answer

A Hosted Zone is a container in Route 53 that stores DNS records for a domain. Route 53 looks up these records to resolve domain names to IP addresses or AWS resources. Public Hosted Zones are used for internet-facing domains, while Private Hosted Zones are used for internal DNS resolution within a VPC.
